MemoryGame (2024) #Unity

Game Developers

          เป็นโปรเจคฝึกงาน เพื่อสร้างพื้นฐานการสื่อสารระหว่าง Server To Player
ผมทำหน้าที่สร้าง Player 2 คนขึ้นมาเพื่อให้คุยกันโดยผ่านตัว FakeServer ที่รุ่นพี่ได้สร้างขึ้น

🚨🚨ปัญหาที่เจอระหว่างโปรเจค🚨🚨
- การส่งข้อมูลระหว่างผู้เล่นกับผู้เล่น
- การคำนวณฝั่งเซิฟเวอร์แล้วส่งค่ากลับไปหาผู้เล่นทั้งหมด
- การสร้างเงือนไขพิเศษ และ แตกต่างกัน เช่นผู้เล่นคนแรก +10 แต่คนที่สอง -10

🔧🔧แก้ไข🔧🔧
- ปรับเปลี่ยนความคิดว่าผู้เล่นมีสิทธิ์อะไร หรือ ไม่มีสิทธิ์อะไร เช่น ผู้เล่นมีสิทธิ์ส่งคำรองไปหา Server แล้วให้ Server ดูว่าผู้เล่นนั้นกระทำได้หรือไม่แล้วส่งค่ากลับไปหาผู้เล่นคนนั้น
- เพิ่มตัวเก็บ ID Player ของแต่ละคนไว้ฝั่ง Server แล้วทำตัวMethod ที่ไว้สำหรับส่งข้อมูลไปหาผู้เล่นทุกคนโดยฝั่งผู้เล่นสามารถ Request หรือขอฝั่งServer ได้อย่างเดียว
- ให้ฝั่งผู้เล่นรับคำสั่งSeverทุกครั้งที่มีการจบเกมและส่งคำขอตรวจสอบว่าตอนนี้ผู้เล่นคนไหนคะแนนเท่าไรเพื่อนำมาแสดงผลของตัวเอง
